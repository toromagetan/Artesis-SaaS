# Arsip — Contoh Konfigurasi Server

Folder ini berisi contoh konfigurasi server (`nginx-artesis.conf`,
`artesis-queue.service`) yang dipakai pada pemasangan sebelumnya.

Statusnya **contoh/rujukan historis — bukan konfigurasi aktif dan bukan
pedoman deployment saat ini.** Topologi deployment produksi (**OD-1**)
belum diputuskan pemilik proyek; sesudah OD-1 ditutup, konfigurasi pada
pemasangan nyata ditulis dan diverifikasi di server tujuan, lalu contoh
di folder ini diperbarui atau diganti mengikutinya. Prosedur pemasangan
generik ada di `docs/DEPLOY-RUNBOOK.md`.
