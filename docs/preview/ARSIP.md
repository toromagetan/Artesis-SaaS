# Arsip — Pratinjau Desain Historis

Folder ini berisi pratinjau HTML historis (era pra-SaaS) yang menjadi dasar
keputusan tata letak yang tercatat di Blueprint (ADR-013 sidebar,
ADR-018 tombol sejajar). Isinya **artefak historis**: dipertahankan apa
adanya sebagai bukti keputusan desain, **bukan** pedoman desain aktif dan
bukan spesifikasi yang harus diikuti untuk pekerjaan baru.

Kontrak tampilan yang berlaku saat ini ada di `docs/PRD-DETAIL.md`
(Prinsip Tampilan) dan Blueprint Bagian kontrak UI.
